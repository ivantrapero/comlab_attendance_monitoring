# ComLab Attendance Monitoring

A web-based attendance monitoring system for computer laboratory instructors. It helps working student to record attendance, view attendance summaries, and generate reports.

## Features

* Instructor attendance monitoring
* Dashboard with attendance summary
* Attendance records and filtering
* Reports generation
* Firebase Authentication
* Firestore database
* Notifications
* Settings and profile management

## Tech Stack

* React 19
* Vite 8
* Firebase Authentication
* Firebase Firestore
* JavaScript / JSX
* CSS
* Lucide Icons
* XLSX

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/ivantrapero/comlab_attendance_monitoring.git
cd comlab_attendance_monitoring
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the application

```bash
npm run dev
```

The application will run locally using the Vite development server.

## Build

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## Firebase

The system uses Firebase for:

* User authentication
* Attendance data storage
* Firestore database
* Hosting and other Firebase services

Make sure your Firebase project is properly configured before deployment.
